"Di dalam sebuah rangkaian tertutup (loop), jumlah aljabar gaya gerak listrik (ϵ) ditambah dengan jumlah aljabar penurunan tegangan (I · R) sama dengan nol."

$$\sum \varepsilon + \sum (I \cdot R) = 0$$
Arus Rangkaian 1 Loop
$$I = \frac{-\sum \varepsilon}{\sum R} = \frac{\varepsilon_1 - \varepsilon_2}{R_1 + R_2 + R_3}$$

Perilaku fisika rangkaian dihitung secara real-time di dalam fungsi calculatePhysics() menggunakan hukum kekekalan energi listrik (Σε + Σ(I·R) = 0): 

// 1. Mode 1 Loop: ΣE + I * R_total = 0
const R_total = R1 + R2 + R3;
const termE1 = loop1Dir === 'cw' ? -E1 : +E1;
const termE2 = loop1Dir === 'cw' ? +E2 : -E2;
const I_loop = -(termE1 + termE2) / R_total;

// 2. Mode 2 Loop: Eliminasi Matriks 2x2 (Arus Mesh I1 & I2)
const det = (R1 + R2) * (R2 + R3) - R2 * R2;
const I1_cw = (E1 * (R2 + R3) - E2 * R2) / det;
const I2_cw = (-(R1 + R2) * E2 + R2 * E1) / det;
const I_mid_down = I1_cw - I2_cw; // Hukum I Kirchhoff di simpul B
  • Tanda Positif/Negatif GGL: Ditentukan oleh perbandingan polaritas baterai terhadap arah penelusuran loop (loop1Dir).
  • Kecepatan & Arah Animasi: Fungsi drawParticlesOnPath() menggerakkan titik muatan sebanding dengan nilai I; jika I < 0, arah gerak otomatis berbalik.

Konsep & Aturan Tanda Hukum II Kirchhoff

Bunyi Hukum II Kirchhoff (Hukum Tegangan / Loop):

"Jumlah aljabar perubahan tegangan (beda potensial) yang mengelilingi suatu lintasan tertutup (loop) dalam suatu rangkaian listrik selalu sama dengan nol."

$$\sum \varepsilon + \sum (I \cdot R) = 0$$

Aturan Tanda GGL (ε):

  • Jika arah loop bertemu kutub negatif (−) lebih dulu lalu ke positif (+), maka ε bertanda negatif (−) dalam persamaan ΣE + ΣIR = 0 (potensial naik).
  • Jika arah loop bertemu kutub positif (+) lebih dulu lalu ke negatif (−), maka ε bertanda positif (+) (potensial turun).

Aturan Tanda Kuat Arus (I):

  • Jika arah penelusuran loop searah dengan arah arus I, maka + I·R.
  • Jika hasil akhir perhitungan I bernilai negatif (−), artinya arah aliran arus sebenarnya berlawanan dengan arah loop acuan yang dimisalkan.

Perbedaan Arus Konvensional vs Aliran Elektron:

Arus Konvensional didefinisikan mengalir dari potensial tinggi (kutub +) menuju potensial rendah (kutub −). Sebaliknya, secara fisis Elektron bermuatan negatif sehingga bergerak dari kutub negatif (−) menuju kutub positif (+).
